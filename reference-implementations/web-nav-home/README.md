# Web Nav-mode Home React Reference

Authoritative React translation of the desktop Navigation-mode home, including
the approved hero banner, quick actions, request cards, recommendation carousel,
asset mappings, screen-reader semantics, and keyboard focus states.

```bash
npm install
npm run dev
```

The implementation source is intentionally self-contained in this directory.
Do not recreate the screen from prose when these files are available; reuse
`src/App.jsx` and `styles.css` as the primary implementation reference.
